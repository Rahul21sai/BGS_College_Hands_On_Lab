# Workshop project

This is a synthetic BGS College food-cart exercise. It does not submit an order or payment.

- Work only in this workshop folder.
- The announced starter bug is quantity handling in cart.js.
- Keep the existing input validation and tests.
- Add no dependencies for the initial repair.
- Tests: `npm test` (Node built-in test runner).
- App: `npm start`, then open http://127.0.0.1:8085.
- First propose a brief plan. After editing, show the diff and run the same tests.
- Report observed output; do not claim an unexecuted test passed.
- Keep credentials out of files, prompts and screenshots. Ask before unrelated changes.
