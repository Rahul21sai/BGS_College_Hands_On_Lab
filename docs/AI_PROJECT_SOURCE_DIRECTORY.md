## Choose a project that you can explain

Read an individual example before installing it. Check its licence, data requirements, model and service access, hardware needs and actual test coverage. Begin with a small reproducible example, then add your own feature and evaluation.

Keep larger fine-tuning, multi-service or deployment projects for study after the workshop. Official SDK examples and community demo collections serve different purposes; a large collection is not evidence that every example is production-ready.
