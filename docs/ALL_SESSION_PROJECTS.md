The original class labs for Sessions 1–3 were completed on Day 1. Their two practice options remain available for follow-up work.

For Sessions 4–6, spend 75 minutes on the original class lab, including setup, demonstration and checks. The facilitator chooses one of the two practice options for a 40-minute demonstration and hands-on slot, then allows 5 minutes to save and wrap up. Neither A nor B is preselected; the other option and extensions are for later practice. Session 4B uses the GitHub project explorer.

Colab links open the shared Drive notebooks. GitHub notebook links provide the source for [forking and saving your work](../README.md#fork-and-save-your-work); the task links explain each practice problem and its checks.

## Evidence and portfolio value

For a chosen project, keep the changed input, code or prompt; the actual tool response or observed check; and an explanation of one limitation. A guided baseline is a learning starter. Portfolio value comes from a useful extension, independent checks, clear documentation and an honest statement of your contribution.

Use engine labels accurately: test fixtures and deterministic workflow outputs are not live model answers, and retrieval alone is not generated text. Live model availability, provider quota and cloud runtime behaviour still need a preflight for your account.
