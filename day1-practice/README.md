## How to practise

1. Run the documented baseline and inspect its engine label.
2. Complete one or more student changes, then repeat the relevant check.
3. Where you enable real model calls, use Colab Secrets and review the configured model access.
4. Save actual outputs, changed code or prompts, and a few sentences about a limitation.
5. Keep fixtures, source retrieval and live model answers distinct when describing the work.

Each session README lists prerequisites, test checkpoints and verified source references. These practice projects complement the existing original Colabs and assignment handouts.
